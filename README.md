# SchoolGear Liberia — Desktop Application

[![Electron](https://img.shields.io/badge/Electron-7.11.2-47848F?logo=electron&logoColor=white)](https://www.electronjs.org/)
[![Vite](https://img.shields.io/badge/Vite-Plugin--Vite-646CFF?logo=vite&logoColor=white)](https://vitejs.dev/)
[![Build Status](https://img.shields.io/badge/Platform-Windows%20x64-0078D6?logo=windows&logoColor=white)](#building-the-installer)

An official cross-platform desktop application built with **Electron** and **Vite** for **SchoolGear Liberia**, delivering a seamless native desktop wrapper for the web-based Learning Management System & Portal.

---

## 🔗 Official Portal & Resources

- **Live Web Portal:** [https://schoolgearliberia.com/](https://schoolgearliberia.com/)
- **School Portal Access:** [https://schoolgearliberia.com/login](https://schoolgearliberia.com/login)

---

## 🚀 Features

- **Native Desktop Experience:** Runs as a dedicated Windows executable (`.exe`) with native taskbar integration.
- **Custom Branding:** Styled with official custom icons, title bar branding, and dedicated shortcuts.
- **Optimized Build Engine:** Powered by **Electron Forge** with **Vite** for fast hot-module reloading and lightweight production bundles.
- **Seamless Web Integration:** Directly renders the live portal interface with auto-hiding navigation bars for maximum productivity.

---

## 🛠️ Tech Stack

- **Framework:** Electron
- **Build System & Packaging:** Electron Forge (Squirrel Installer)
- **Bundler:** Vite
- **Runtime:** Node.js

---

## 💻 Development Setup

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [npm](https://www.npmjs.com/) package manager

### Installation

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/YOUR_USERNAME/schoolgear-liberia-desktop.git](https://github.com/YOUR_USERNAME/schoolgear-liberia-desktop.git)
   cd schoolgear-liberia-desktop
   ```
